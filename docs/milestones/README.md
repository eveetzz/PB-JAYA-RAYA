## Cara Penggunaan Milestone
1. Setiap modul/fitur baru akan memiliki file milestone tersendiri di folder `docs/milestones/`.
2. Kemajuan backend & frontend wajib diperbarui pada status checklist di file milestone terkait.
3. `MS-04` sampai `MS-06` dikerjakan sebagai satu paket (modul Pelatih/Official) dan didokumentasikan bersama dalam [`04-pelatih-official-completed.md`](./04-pelatih-official-completed.md).
4. Status `In Progress` berarti sebagian scope selesai; rincian bagian yang tersisa dicatat di bagian **Sisa Pekerjaan** pada file milestone terkait.
